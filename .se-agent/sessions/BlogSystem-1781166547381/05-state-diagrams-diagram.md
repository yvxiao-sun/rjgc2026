```mermaid
stateDiagram-v2
    [*] --> 草稿 : 创建文章
    草稿 --> 已发布 : 点击发布
    草稿 --> 已删除 : 删除草稿
    已发布 --> 草稿 : 编辑并保存为草稿
    已发布 --> 已下架 : 作者下架文章
    已发布 --> 已删除 : 作者删除文章
    已下架 --> 已发布 : 重新发布
    已下架 --> 已删除 : 删除文章
    已删除 --> [*] : 永久删除
    
    state 草稿 {
        [*] --> 编辑中
        编辑中 --> 保存中 : 自动保存
        保存中 --> 编辑中 : 保存完成
    }
    
    state 已发布 {
        [*] --> 展示中
        展示中 --> 被浏览 : 用户访问
        被浏览 --> 展示中 : 浏览量+1
    }
    
    note right of 草稿 : 只有作者可见
    note right of 已发布 : 所有用户可见
    note right of 已下架 : 仅作者和管理员可见
```
