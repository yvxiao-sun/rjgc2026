**描述**: 基于博客系统的三个核心业务流程：发布文章、评论互动和文章搜索筛选，使用Mermaid流程图语法绘制了包含分支判断和循环的活动图。每个流程都包含了用户操作、系统验证、条件分支和循环返回等关键元素，完整展示了业务流转过程。

## 活动图 1: 发布文章流程

**描述**: 作者从登录到成功发布文章的完整业务流程，包含文章内容验证和发布确认

```mermaid
flowchart TD
    A([开始]) --> B[用户登录]
    B --> C{登录成功?}
    C -->|否| D[显示错误信息]
    D --> B
    C -->|是| E[进入写作页面]
    E --> F[填写标题和正文]
    F --> G[选择分类和标签]
    G --> H{内容验证}
    H -->|标题为空| I[提示标题不能为空]
    I --> F
    H -->|正文为空| J[提示正文不能为空]
    J --> F
    H -->|验证通过| K[点击发布按钮]
    K --> L{确认发布?}
    L -->|否| M[返回编辑]
    M --> F
    L -->|是| N[保存文章到数据库]
    N --> O[生成文章摘要]
    O --> P[更新文章列表]
    P --> Q([结束])```

## 活动图 2: 评论互动流程

**描述**: 用户浏览文章、发表评论及回复评论的完整交互流程，包含评论验证和嵌套回复处理

```mermaid
flowchart TD
    A([开始]) --> B[浏览文章]
    B --> C[查看评论区]
    C --> D{用户已登录?}
    D -->|否| E[显示登录提示]
    E --> F[用户登录]
    F --> G{登录成功?}
    G -->|否| H[返回登录]
    H --> F
    G -->|是| I[返回文章页面]
    I --> C
    D -->|是| J[输入评论内容]
    J --> K{内容验证}
    K -->|内容为空| L[提示评论不能为空]
    L --> J
    K -->|内容过长| M[提示内容超限]
    M --> J
    K -->|验证通过| N[提交评论]
    N --> O{是否回复?}
    O -->|否| P[保存为顶级评论]
    O -->|是| Q[选择目标评论]
    Q --> R[保存为嵌套回复]
    P --> S[刷新评论区]
    R --> S
    S --> T{继续评论?}
    T -->|是| J
    T -->|否| U([结束])```

## 活动图 3: 文章搜索与筛选流程

**描述**: 用户通过关键词搜索或分类标签筛选文章的完整流程，包含多条件组合查询和结果展示

```mermaid
flowchart TD
    A([开始]) --> B[进入文章列表页]
    B --> C{选择操作}
    C -->|关键词搜索| D[输入搜索关键词]
    C -->|分类筛选| E[选择文章分类]
    C -->|标签筛选| F[选择文章标签]
    C -->|时间排序| G[选择时间范围]
    D --> H[执行搜索]
    E --> I[执行筛选]
    F --> I
    G --> I
    H --> J[系统查询数据库]
    I --> J
    J --> K{查询结果}
    K -->|无结果| L[显示空状态提示]
    L --> M{重新搜索?}
    M -->|是| C
    M -->|否| N([结束])
    K -->|有结果| O[展示文章列表]
    O --> P[分页显示]
    P --> Q{浏览更多?}
    Q -->|是| R[翻页查看]
    R --> O
    Q -->|否| S{调整筛选条件?}
    S -->|是| C
    S -->|否| N```
