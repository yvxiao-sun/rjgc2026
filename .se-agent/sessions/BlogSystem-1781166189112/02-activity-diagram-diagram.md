```mermaid
flowchart TD
    A([开始]) --> B[用户登录]
    B --> C{登录成功?}
    C -->|否| D[显示错误信息]
    D --> B
    C -->|是| E[进入写作页面]
    E --> F[填写标题和正文]
    F --> G[选择分类和标签]
    G --> H{内容验证}
    H -->|标题为空| I[提示标题不能为空]
    I --> F
    H -->|正文为空| J[提示正文不能为空]
    J --> F
    H -->|验证通过| K[点击发布按钮]
    K --> L{确认发布?}
    L -->|否| M[返回编辑]
    M --> F
    L -->|是| N[保存文章到数据库]
    N --> O[生成文章摘要]
    O --> P[更新文章列表]
    P --> Q([结束])```
